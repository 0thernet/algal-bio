# Biology discovery implementation status

The initial implementation uses Algal Lab for study semantics, ALGAL for runtime
evidence, algal-bio for biology, and optional local source exports for Sponge.
The Anthropic ART report motivated the architecture; this project has not
reproduced that system, its scale, or its findings.

| Planned phase | Delivered scope | Remaining qualification |
| --- | --- | --- |
| 1. Public foundation | Pinned environment, offline checks and fixture, all historical evidence retained | Legacy native studies are separately unqualified |
| 2. Observation boundary | Registered prediction, delayed measurement, immutable joins, selection freeze, receipt replay and fresh computation | New adapters must declare their full executed source closure |
| 3. Biology registration | Source-bound audit of 75 libraries, assay eligibility, independent-unit exclusions and frozen calibration endpoint | A new matched/crossed cohort and domain-reviewed independent endpoint |
| 4. Biology instrument | RNA pre-TMM filtering and coordinate-matched descriptive C-score arithmetic; independent calculations | Full differential-expression/raw omics pipelines and valid cross-modality biological joins |
| 5. Campaign controller | Append-only decisions, reservations, idempotent fake-provider recovery, evidence review, bounded data broker | Actual OS isolation, live provider expiry/resource enforcement and model integration remain disabled |
| 6. Qualification | Three repeated scripted calibration runs, actual lab receipts, independent arithmetic, retained failures, review evidence handoff | Funded live single-investigator/multi-agent comparison with matched access and resources |
| 7. Prospective search | Executable no-go gate and retained readiness decision | **Not run**; no search, holdout evaluation or novelty claim occurred |
| 8. Public release | Software, data audit, calibration and reproduction record with explicit rights manifest | Biological and wet-lab follow-up require a separate registered study |

The change from a prospective biology release to a software/calibration release
follows the data audit. The cardiomyocyte and mESC studies differ in perturbation,
age, cell preparation, genome annotation and study. Replicate library names do
not establish independent animals/cultures. Additional modeling cannot identify
an otherwise confounded cell-context effect.

The coordinator has no external-provider or generated-code execution route. Its
role arguments and data broker constrain calls through this API; they are not an
operating-system security boundary. A future live implementation must qualify
separate investigator/evaluator mounts, restricted tools/network, hard provider
expiry, quota enforcement and credential handling before activating that route.
The current trusted local biology tool executes only checked-in code over the
fixed public fixture. Its subprocess is bounded and uses isolated Python startup.

The next research decision is to select an independently evaluable biological
design with a domain reviewer. The next operational decision is an explicit
funded envelope and a qualified provider/sandbox. Neither follows automatically
from a passing fixture, and editing configuration alone cannot enable them.
